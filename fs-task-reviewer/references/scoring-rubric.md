# **Senior Reviewer: Importance Rubric**

| Score | Meaning | Action for Implementation Agent |
| :---- | :---- | :---- |
| **10/10** | **Critical** | Blockers: Security risks, broken tests, or 0% coverage on new logic. |
| **7-9/10** | **Major** | Tech Debt: SOLID violations, missing YARD/TSDoc on public methods, or N+1 queries. |
| **4-6/10** | **Moderate** | Maintainability: Complex methods needing breakdown or suboptimal variable naming. |
| **1-3/10** | **Nit** | Polish: Minor style adjustments or slight refactors for readability. |
