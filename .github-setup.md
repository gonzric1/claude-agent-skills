# GitHub Setup Instructions

To push this repository to GitHub:

1. Create a new repository on GitHub:
   - Go to https://github.com/new
   - Repository name: `claude-agent-skills`
   - Description: "Reusable Agent Skills for Claude Code"
   - Make it public or private (your choice)
   - Don't initialize with README (already exists)

2. Add GitHub as remote and push:
   ```bash
   cd ~/repos/claude-agent-skills
   git remote add origin https://github.com/YOUR_USERNAME/claude-agent-skills.git
   git branch -M main
   git push -u origin main
   ```

3. Update the install.sh script with your GitHub URL:
   - Replace `https://github.com/gonzric1/claude-agent-skills.git`
   - With your actual GitHub URL

4. Update README.md with correct GitHub URLs

## After Setup

Test installation on another machine:
```bash
curl -fsSL https://raw.githubusercontent.com/YOUR_USERNAME/claude-agent-skills/main/install.sh | bash -s /path/to/project
```
